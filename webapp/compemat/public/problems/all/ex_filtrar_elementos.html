Neste exercício você deve criar um programa que receba como entrada uma lista l e um número n e que tenha como saída uma lista contendo todos os elementos de l maiores ou iguais a n.

Caso não existam, o programa deve produzir como saída uma lista vazia. Os elementos devem aparecer na lista de saída na mesma ordem em que parecem na lista de entrada.

Entradas

Uma lista l e um número n.

Saída

Uma lista contendo os elementos de l maiores ou iguais a n.

Exemplo

Entrada Saída
l=[1, 2, 3, 4, 5, 6, 7]
n=5 		[5, 6, 7]
