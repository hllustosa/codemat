Uma tabuada é uma tabela contendo os resultados de operações aritméticas básicas. A tabuada de multiplicação é uma das mais utilizadas pelas crianças em idade escolar para se familiarizar com os resultados e facilitar os cálculos.

Neste problema você deve criar um programa que gere tabuadas. O programa tem como entrada um valor n e deve produzir como saída uma sequência de cadeias de caracteres com as expressões de múltiplicação. Por exemplo, considere a tabuada a ser gerada quando n=7:

7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
7 x 6 = 42
7 x 7 = 49
7 x 8 = 56
7 x 9 = 63
7 x 10 = 70

Entradas

Um número inteiro n.

Saída

Uma sequência de cadeias de caracteres contendo a tabuada de n.
