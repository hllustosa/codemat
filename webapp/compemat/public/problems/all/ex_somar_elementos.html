Neste exercício você deve criar um programa que receba como entrada uma lista de números l e que produza como saída um número contendo a soma de todos os elementos da lista.

Entradas

Uma lista l.

Saída

Um número contendo a soma dos elementos da lista.

Exemplo

Entrada Saída
l=[1, 2, 3, 4, 5, 6, 7] 28
