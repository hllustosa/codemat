Neste problema, você deve criar um programa que tenha como entrada um único número n. O programa deve verificar se o número é positivo ou negativo e produzir a cadeia de caracteres "positivo" ou "negativo" respectivamente em cada caso. A entrada 0 (zero) não precisa ser tratada.

Entradas

Um número n que deve ser verificado.

Saída

Uma cadeia de caracteres contendo a mensagem adequada.

Exemplos

    Entrada:
       n=215
    Saída:
       positivo

    Entrada:
       n=-54
    Saída:
       negativo
