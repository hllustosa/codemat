Quando aprendemos uma nova linguagem de programação, tradicionalmente, o primeiro programa que escrevemos nesta nova linguagem é chamado Hello World, ou Olá mundo em português. Geralmente, trata-se de um programa simples que apenas produz como saída a mensagem "Hello World".

Neste problema, sua tarefa é apenas um pouco mais complicada que desenvolver um programa do tipo. O programa a ser produzido neste exercício deve emitir mensagens personalizadas para cada usuário. Você deve criar um programa que receba como entrada o nome de uma pessoa e produza como saída a mensagem "Olá, ", seguida pelo nome da pessoa que recebeu como entrada. Note ser necessário respeitar o único espaço em branco após a vírgula.

Entradas

Uma cadeia de caracteres nome contendo um nome de usuário.

Saída

Uma cadeia de caracteres contendo a mensagem: "Olá, " seguida pelo nome do usuário.

Exemplos

Entrada Saída
nome=Maria Olá, Maria
