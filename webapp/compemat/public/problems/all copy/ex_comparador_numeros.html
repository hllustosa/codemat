Neste problema, você deve criar um programa que tenha como entrada dois números n1 e n2. O programa deve tratar três possibilidades distintas e emitir uma saída conforme cada caso. Caso n1 seja maior que n2, o programa deve produzir a cadeia de caracteres "n1 é maior". Caso n2 seja maior que n1, o programa deve deve produzir a cadeia de caracteres "n2 é maior". Casos n1 seja igual a n2, o programa deve produzir a cadeia "iguais".

Entradas

Dois números n1 e n2 que devem ser comparados.

Saída

Uma cadeia de caracteres contendo a mensagem adequada.

Exemplos

    Entrada:
       n1=215
       n1=124
    Saída:
       n1 é maior

    Entrada:
       n1=106
       n1=245
    Saída:
       n2 é maior

    Entrada:
       n1=108
       n1=108
    Saída:
       iguais
