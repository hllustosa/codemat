
# Comp & Mat Web Page

This is the repo for the Comp & Mat project web page. Currently developed as a react SPA webapp backed by a Firebase App.

## Set up

Install firebase CLI

```
npm install -g firebase-tools
```

Problems while running firebase CLI o Windows, do this:

```
Set-ExecutionPolicy RemoteSigned
```

Login to firebase

```
firebase login
```

To bind this to the remote Firebase project (if not already)
```
firebase init
```

To deploy any project
```
cd [PROJECT FOLDER]
firebase deploy
```
